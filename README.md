## 📌 Descripción

NOVA es un e-commerce frontend 

## 🚀 Funcionalidades

- Página de inicio con productos destacados.
- Catálogo dinámico.
- Productos almacenados en un array de objetos.
- Carga asíncrona simulada con Promise + setTimeout + async/await.
- Renderizado dinámico mediante DOM.
- Buscador de productos.
- Página de detalle de producto.
- Carrito simulado con contador y localStorage.
- Formulario de contacto con validación.
- Mensaje de éxito generado dinámicamente.
- Diseño responsive Mobile First.
- Navegación responsive para dispositivos móviles.
